## Old Computer Support

This project is designed to run smoothly on older and low-spec machines. The following practices are followed to keep resource usage low:

- **Minimal dependencies** – only essential packages are included to reduce install size and startup time.
- **No heavy build tools** – the project avoids resource-intensive bundlers and compilers where possible.
- **Lightweight runtime** – the application is optimised for low CPU and memory consumption.
- **Graceful degradation** – features are implemented in a way that works on older browsers and slower hardware.

If you experience performance issues, please open an issue and we will investigate further.
